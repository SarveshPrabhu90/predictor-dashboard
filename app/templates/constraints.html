How to Interpret

  • recommendation_safe = true means every constraint passes when the modelless recommendation is checked against the noise-free explicit baseline.
  • Output differences between modelless predictions and baseline outputs arise because the learned model trains on noisy data. Small differences are expected.
  • Purity constraint is the most critical — if purity falls below the threshold under baseline verification, the recommendation is not safe for production.
  • Input range constraints should always pass since the LP optimizer enforces bounds. They're included as a sanity check.

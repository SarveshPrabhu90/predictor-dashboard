How to Interpret

  • Mean residual ≈ 0 means the predictor is unbiased — it doesn't systematically over- or under-predict.
  • P90 / P95 — 90% / 95% of predictions have an absolute error below this value. Useful for worst-case guarantees.
  • Residual vs Predicted — random scatter is ideal. A funnel shape means error grows with magnitude (heteroscedasticity). A curve means the linear model is missing a nonlinear term.
  • Residual vs Input — trends mean the model under-fits that input's contribution. For a truly linear system, these should be flat.
